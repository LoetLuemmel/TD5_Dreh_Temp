TJA1021T K-Line Interface für TD5 ESP32

Hinweis: Der TJA1021T ist ein LIN-Transceiver, funktioniert aber auch für ISO 9141-2 (K-Line) bei 10400 Baud. Verwende die /10 Variante (TJA1021T/10) für optimale Kompatibilität.

Pinbelegung TJA1021T (SO8)

Pin Name Funktion Verbindung
1 RXD Receive Data (Open-Drain) ESP32 GPIO16 + 10kΩ Pull-up zu 3.3V
2 SLP_N Sleep Control (LOW=Sleep) +3.3V (immer aktiv)
3 WAKE_N Wake-up Input +3.3V (nicht verwendet)
4 TXD Transmit Data Input ESP32 GPIO17
5 GND Masse GND
6 LIN LIN/K-Line Bus OBD-II Pin 3 + 1kΩ Pull-up zu 12V
7 VBAT Batteriespannung +12V (OBD-II Pin 16)
8 INH Inhibit Output Offen lassen (oder für Spannungsregler)

OBD Pin Funktion Verbindung
3 K-Line TJA1021T Pin 6 (LIN)
4 Chassis GND GND
5 Signal GND GND
16 +12V Batterie TJA1021T Pin 7 (VBAT)
Wichtige Hinweise:
  • Verwende unbedingt die TJA1021T/10 Variante (10.4 kBd) - nicht die /20 Variante!
  • Der RXD-Pin ist Open-Drain - der 10kΩ Pull-up ist zwingend erforderlich
  • Der 1kΩ Pull-up am LIN-Pin dient als Master-Terminierung
  • Abblockkondensatoren möglichst nah am IC platzieren
  • Der TJA1021T echoiert gesendete Bytes - der Code berücksichtigt das bereits
